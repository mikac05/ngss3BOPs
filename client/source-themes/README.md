# IN and SF homepages

Open `index.html?theme=IN` or `index.html?theme=SF` through a browser, or use the customization page's preview. `auth=loggedOut` shows the signed-out header. The default is signed in.

Artwork is extracted from user-supplied SVGs; source manifests identify the files. Native HTML/CSS handles layout, game grids, navigation, search and the expandable activity dock. The same page accepts the customization prototype's resolved preview configuration.

Current visual variants: one IN gold/purple theme and one SF starfield theme. Carousel frames, login state and expanded tools are states within these variants. No real account actions, payments or external message sending.

The compact SF signed-in reference shows a scrolled screen with sticky header/category controls. Scroll the HTML page to compare that state. IN has three game columns; SF has four.
