阶段一：业务价值与玩法

💡 活动基本
  • 单款指定游戏 ＋ 倍率门槛闯关 ＋ 3×3 Bingo 连线 的非同步派奖活动。
    玩家下注达标后挑战倍率，命中点亮棋盘并派彩，连线成功再领加码大奖。
👤 1. 面向对象
  • 全平台玩家参与
    支持后台依「会员分层」开启准入。
  • 无需手动报名
    符合投注条件自动计入挑战。
🎮 2. 怎么玩
  • 限定单款指定游戏
    例如：Spribe Sp飞行员
  • 单笔下注达最低门槛
    例如：单笔有效投注 ≥ ₹ 10.00
💰 3. 怎么领
  • 基础目标奖：单笔命中倍率门槛即发。
  • Bingo 连线奖：任 3 格成线额外领大奖。
  • Happy Hour：指定时段基础奖享 2.0× 翻倍。
⚠️ 架构原则：非同步显示
  • 注单有延迟
    游戏商结算与回调需时，收到注单后才有办法计算结果。
  • 活动页
    不做游戏内假弹窗与推测进度；玩家回访活动页时同步已确认成果。

阶段四：核心业务逻辑

🎯 规则 1：单笔注单命中（一注一目标、不回补）
  • 最高未完成单一命中
    单笔注单仅匹配「门槛 ≤ 实际倍率」中最高且未完成的单一目标。
  • 不向下回补低阶目标
    例如命中 65× ➜ 仅完成 50× 目标，10× 与 30× 仍保持未完成。
  • 每人每目标限领一次
    活动周期内每个目标仅派发一次基础奖励。
🧮 算法现场试算器（未解锁：10×, 30×, 50×, 80×, 150×）
👉 命中：50× 门槛（10×、30× 保留未解锁）
🎲 规则 2：Bingo 3×3 棋盘
  • 池盘分离：目标池可有 N 个（如 11 个），棋盘固定取 9 个。
  • 点亮条件：命中目标位于 9 宫格内才点亮。
  • 8 条独立线：3 横 + 3 直 + 2 斜，成线即刻发奖。
🔥 规则 3：Happy Hour 加码
  • 时段限定：在设定时段内命中基础目标。
  • 仅基础奖加成：享受 2.0× 翻倍。
  • Bingo 连线奖不加倍。
🚫 规则 4：每日预算上限
  • 额度发完即止：达到每日预算上限后停止派彩。
  • 后续注单直接不发：不排队、不延期。
  • 每日 00:00 (UTC+8) 重置。
06

阶段六：边界异常防御与工程验收清单

🛡️ 1. 幂等去重保证
  • 全局唯一识别
    同一注单重复推送不重复发奖，保证系统资金安全。
🛡️ 2. 高频并发防护
  • 玩家级串行化结算
    确保同一玩家多笔并行结算注单依序点亮棋盘，防止状态覆盖。
🛡️ 3. 延迟与 VOID 撤销
  • 超长延迟注单：活动期内产生之注单延迟回调仍合法派彩。
  • VOID 撤销注单：不自动追扣负余额，记录差异流水转人工日对账。
🛡️ 4. 跨日水位重置（00:00 UTC+8）
  • 预算水位重置：每日预算额度换日自动归零重启。
  • 前端静默刷新：换日时玩家端自动拉取最新上限状态。
