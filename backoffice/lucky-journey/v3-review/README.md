# 好运探索季 V3 独立评审版

更新于 2026-09-14。Prototype-only。基于用户指定 V3 规格及后续明确修正；本版本独立于上层参考页面，无线上变更或 Git 提交。

## 入口

- `index.html`：基本资料不编号，后续为 1 转盘开奖与进度设置、2 抽奖次数、3 预算。左侧 NGSS 菜单，右侧等宽总览。
- `player.html`：玩家转盘、获奖弹窗、预算及仿真。情境与操作收于浮动「开发工具」。
- `guide.html`：管理员规则、公式及设置流程。
- `CALCULATION.md`：计算模型、条件概率、预算、生产事务建议及未实现边界。

使用本机 HTML，不依赖 CDN。Element Plus 风格样式，未加载 Vue / Element Plus 库。

## 当前规则

- 全体同规则，不区分玩家等级。第一转可设 1–95%，默认 90%，保证达到设定进度。
- 三阶段只分配剩余 T−1 次，并针对首转之后的剩余进度推进；谢谢参与扣次不加进度，末转保证补满。
- 每阶段均能抽金币、宝石、星钻。建议的中奖条件概率分别为 70/25/5、20/60/20、5/25/70；后台可调整，合计联动为 100%。谢谢参与是独立概率。
- 道具类型不影响当前转的进度增量。金币最多四位小数、宝石两位、星钻整数，进度以整数百万分之一存储。只在完成时发放一次固定现金奖金。
- 每日免费固定开页发放；好友人数不限、每局助力次数封顶；任务按每局有效新增行为完成一次。来源顺序为免费、好友、任务。
- 总解锁次数位于右侧抽奖次数卡下方；全部来源不足时直接提示并阻止配置通过。免费＋任务不足只作提示。
- 预算显示总额、可用余额、每次参加预计支出、单次完成奖金、可新增参加与新增参加预计支出。预留不等同派奖。
- 道具中奖弹窗显示实际数量及进度；仅完成弹窗显示现金，区分处理中与已发放，同一结果不重复提示。

## 验证与边界

运行 `node verify.cjs`，jsdom 可由 `LJ_JSDOM` 指定安装路径。2026-09-14：39 组检查通过，包括混合概率阈值、各种道具的进度一致性、优化后的卷积与独立枚举一致、金额精度、弹窗及同请求重试。JavaScript 语法检查通过。

已只读参考 Edge 中打开的倍率巅峰挑战表单。新版 file URL 浏览器视觉验收仍未完成，之前的浏览器访问限制延续；DOM 测试不等于视觉验收。

本次仅优化本机引擎，没有生产数据库、服务端随机源、事务锁、outbox 或真实钱包集成。计算和后端实现边界见 CALCULATION.md。正式资格、活动时区、有效行为、重复参加人数口径及钱包政策仍须平台接口确认。

## 紧凑 UX 与 Pages 发布修订

固定紧凑排版并兼容旧草稿；增加存档状态、更多工具菜单、单一固定表头、名称分段选择、选中色票、首末转里程碑、阶段分界滑杆、道具堆叠条、展开式参加设置和行内错误。来源关闭即收折，配置检查移至侧栏顶端，抽奖次数顶端显示差额。

采纳清晰状态和操作可预测性的建议；保留现有五项任务，不采用建议中误写的三项任务。阶段曲线标注真实计算点，不将剩余进度比例误写成绝对进度。数值输入和分界滑杆并存；未添加装饰性滚动进度条或大面积毛玻璃。43 组测试通过。
