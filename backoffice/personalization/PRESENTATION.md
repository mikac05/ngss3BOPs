# 个性化改版 · 五分钟演示提词

打开 [演示指南](presentation.html)，再进入 [个性化改版](index.html)。建议 PC 浏览器 1920 × 1080，右侧预览保持 390 或 480 px。

开场：**让管理员先选本站默认外观，再决定玩家可选范围，最后用真实网页预览调整组件。**

| 时间 | 在演示页操作 | 讲述重点 |
|---|---|---|
| 0:00–1:00 | 主题与颜色 → NG → 橙白、藍白；取消一个玩家可选颜色 | 默认值与玩家可选范围分开。只开放 NG 和两种颜色，即固定主题、允许有限换色。 |
| 1:00–1:30 | 点「玩家外观」，在右侧切换颜色 | 玩家只看到管理员开放的选项；后台保持 Element Plus 风格。 |
| 1:30–2:30 | 钱包充值 → 样式一、二、三；在预览点金额和渠道 | 选择直接生效。同一份数据、相同功能，不同布局。 |
| 2:30–3:30 | 个人中心 → 样式二；VIP 页面 → 样式三；预览切换等级 | 组件复用，颜色统一。样式不改变真实余额、等级或权益。 |
| 3:30–4:15 | 登录注册 → 样式一、二；切换注册；站内信 → 打开消息 | 预览可操作。配图可以替换，渐隐效果由代码处理。 |
| 4:15–5:00 | 底部导航 → 切换样式；查看修改 → 保存或撤销 | 样式与导航目的地分开。修改集中检查、保存，也能恢复默认。 |

有余裕时再打开「开发工具箱」，演示未登录、加载失败、空内容、租户切换及「运行检查」。不必在主流程逐项解释检查规则。

## 展示范围

- 首页原有 8 组、37 款保留；新增页面 6 组、21 款，共 58 款。
- 登录注册 4、钱包充值 3、个人中心 3、VIP 页面 3、站内信 3、底部导航 5。
- NG 三色：绿黑、橙白、藍白。宽版独立预览、局部更新、保存/撤销、导出配置及开发条件模拟。

## 请 PM 与 UI 确认三件事

1. 默认外观 → 玩家范围 → 组件样式，是否符合租户管理习惯？
2. 哪些样式进入正式范围？各组件默认选择哪一款？
3. 最终配图、图标与视觉细节如何收敛？随后如何安排后端保存、权限、资产管理和数据接口？

结尾：**今天先确定管理方式与保留的样式，再由 UI 收敛细节、开发对接数据。**

## 说明口径

这是可交互概念原型。六个 Figma 命名组与 21 款布局已映射为网页组件；部分装饰图标复用现有资源，登录背景没有逐一复刻所有配色中的不同角色。最终视觉仍需 UI 对照确认。WG / GAME 显示为设计待补，不计入本次 Figma 覆盖。

保存仅在当前页面会话中生效；导出 JSON 可保留提案。没有修改正式站点，不执行真实登录、交易、奖励或消息已读操作。
