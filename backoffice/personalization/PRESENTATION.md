# 個性化改版｜PM／UI 會議提詞

[概念與操作指南](presentation.html) · [開啟個性化頁面](index.html)

## 一句話介紹

管理員先決定站點預設外觀與玩家可選範圍，再透過可操作的 H5 預覽調整元件，最後核對修改並保存。

## 先講清楚三個層次

| 層次     | 決定什麼                       | 例子                       |
| -------- | ------------------------------ | -------------------------- |
| 主題系統 | 配色、元件樣式與預設搭配       | NG 的橙白、藍白            |
| 站點設定 | 管理員選定的預設與個別覆寫     | 預設橙白，錢包採另一款布局 |
| 玩家選擇 | 管理員允許玩家使用的主題與顏色 | 固定 NG，只開放橙白與藍白  |

重點：玩家切換外觀不會改寫站點預設；元件樣式由管理員設定。預設值必須保留在可用範圍內，只留一個選項就能鎖定。

## 五分鐘操作驗證

請使用同一個操作分頁，依序完成。指南按鈕會在本次開啟後返回同一操作分頁；不要重新整理，避免重設演示資料。操作頁保留既有介面語系，以下以正體中文描述相同操作。

| 情境                  | 動作                                                                       | 預期結果                                                         |
| --------------------- | -------------------------------------------------------------------------- | ---------------------------------------------------------------- |
| 1. 固定主題、開放兩色 | 主題維持 NG，預設橙白；玩家範圍取消綠黑，保留橙白與藍白                    | 主題鎖定 NG、開放兩色；預設橙白不能被取消                        |
| 2. 玩家視角           | 點預覽上方的玩家外觀，在預覽選藍白，再切回橙白                             | 玩家只看到允許的選項；本站預設保持橙白                           |
| 3. 局部樣式           | 到錢包充值設定比較樣式二、三；選快捷金額後換樣式，再恢復預設               | 已選金額保留；只有對應區域換布局；恢復後回到跟隨 NG 預設         |
| 4. 使用條件           | VIP 頁面切換登入狀態；工具箱切換空內容與載入失敗，最後恢復已登入、正常內容 | 訪客不顯示會員專屬資料；非正常狀態有對應提示；模擬不成為站點設定 |
| 5. 保存與撤銷         | 查看修改並保存；再改顏色後撤銷；需要留存時匯出 JSON                        | 修改集中呈現；撤銷回到本次會話最後保存版本                       |

指南中的勾選是人工確認進度，不是自動測試或正式驗收。需要檢查原型行為時，另外使用開發工具箱的運行檢查。

## 設計特色的講述順序

1. **可預測的管理權**：站點預設與玩家範圍分開，品牌一致性與有限自由度可以並存。
2. **整體一致、局部可換**：配色共用，元件個別更新，共用資料與結構持續沿用。
3. **預覽就是可操作網頁**：同時檢查布局、輸入、狀態與入口，不只比較靜態外觀。
4. **直接選擇，也可恢復**：選樣式自動建立本站覆寫；恢復預設清除指定；隱藏另有適用條件。
5. **外觀與功能各有責任**：視覺樣式不改變真實餘額、權益或交易規則。
6. **簡潔主流程、按需展開工具**：進階功能、素材設定、條件模擬、配置匯出與檢查不擠占主要選擇流程。

## 請 PM 與 UI 留下的結論

- PM：管理規則與保存流程是否清楚？首版要開放哪些能力？
- UI：樣式差異是否有意義？配色、狀態、長文案與 H5 窄幅是否一致可用？
- 共同產出：確認管理規則、圈定首版範圍、列出待修的體驗與視覺問題。

## 概念原型與正式導入

目前以 NG 三色與 58 款樣式展示可組合的系統，不需在會議逐項列出樣式。WG／GAME 完整設計、最終素材、服務端權限與規則、配置及玩家偏好持久化、真實資料與資產管理流程仍需確認。

保存僅在當前頁面會話生效，重新整理會重設；JSON 匯出可保留提案。全部為合成示例，不執行真實登入、交易或會員資料修改。部分裝飾素材共用，最終視覺需 UI 對照確認。
