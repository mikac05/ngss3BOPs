# 个性化改版说明

[開啟說明頁](presentation.html) · [開啟操作頁](index.html)

## 操作邏輯

- 本站預設與玩家可選範圍分開；預覽試選不改寫本站預設。
- 主樣式用預覽卡片；細部設定用按鈕、開關或清單。
- 「樣式1（現行）」標記供 UI 與 PD／PM 比較，決定保留現行選項或用新設計取代；並列不代表全部保留。
- 首頁由各區塊組合；分類按鈕與資金快捷区在遊戲分類的細部設定。
- 側欄色塊代表選取，筆形高亮代表修改；標題圖示懸停可看預設、覆蓋、恢復與開關說明。

## 主要操作方式

1. 搜尋或展開左側分類。
2. 選主樣式，再調細部選項。
3. 預覽頁面、登入狀態與寬度，點配置檢查查看問題。
4. 點「发布」，核對當前／變更後，再點「确认发布」。

## 情境速查

| 需求 | 操作 | 結果 |
|---|---|---|
| 評估現行選項 | UI 與 PD／PM 對照現行與新設計。 | 確認保留／替換清單，不預設全部保留。 |
| 組合首頁 | 遊戲分類選主樣式，再調「细部设置」的分類按鈕與資金快捷區；遊戲排列、活動摘要分別調整。 | 用各區塊組合版面，沒有獨立的「首頁版面」總選項。 |
| 固定品牌、開放配色 | 在「主题与颜色」設定本站預設與玩家可選範圍，例如只開放橙白、藍白。 | 預設必須在允許範圍內；只留一種選項即可固定。 |
| 只試看，不改本站 | 在預覽選頁面、配色、主題；右上切換登入前後，底列調整寬度或輸入自訂值。 | 只改預覽情境；本站預設不變。只有一個可用主題時無法切換。 |
| 調整底部導航 | 登入前、登入後分別選入口，使用左右箭頭排序。 | 兩組獨立設定；位置不能空白，同組功能不能重複。 |
| 替換 App 下載位置 | 開啟該組「App 下载替代入口」，再選替代功能。 | 使用既有 App 槽位，不增加按鈕數；沒有 App 槽位時不適用。 |
| 補充入口或關閉區塊 | 「替代按钮」選位置、功能、登入範圍；要隱藏元件則用標題旁開關。 | 不支援的位置或缺少必要入口會提示調整；必要元件不可關閉。 |
| 單項恢復 | 使用標題旁恢復圖示，先確認提示範圍。 | 該設定回到預設，其他修改保留；恢復後仍需發布。 |
| 全部撤銷 | 撤銷修改並確認。 | 未發布修改回到上次發布版本，保留既有客製；不是全站恢復主題預設。 |
| 檢查並發布 | 點「配置检查」的非零分類看詳細，處理 Block，確認需復核項；再點「发布」。 | 核對「當前／變更後」，確認無誤後點「确认发布」。預覽不等於發布。 |

## 角色交付規格

### 前端開發人員

- 依確認清單保留穩定樣式 ID；定義被替換選項的舊值映射與回退，不能只刪除卡片。
- 遊戲分類恢復樣式保留細部設定；全部撤銷回到上次發布版本，不等同全站 INHERIT。
- 登入前後導航分開；我的／帳戶正規化為同一入口，App 替代只使用既有 App 槽位。
- 替代入口驗證位置、登入範圍與必要功能可達性；只有相同資料才省略重複檢查。
- App 開關不重建控制項；預覽情境與本站設定分離。

### UI 設計師

- 與 PD／PM 逐物件確認現行樣式的保留／替換與新舊對應。
- 新增選項與主題沿用既有物件分類；同物件的不同外觀放在同類選項。
- 布局變化是主樣式，分類按鈕與資金快捷區等是細部設定，不另拆物件。
- 新主題依各物件提供樣式與預設搭配，標明共用、新增、不適用。
- 用途不同才討論新增分類，避免同功能因外觀不同而重複分類。

## 簡報使用

說明頁提供簡報模式，左右方向鍵切換章節、Esc 結束；列印時每章分頁。兩張 SVG 為工作區與恢復範圍示意圖，非實際截圖。

說明頁提供台灣繁體與中國簡體切換，正文、提示與示意圖同步使用各地慣用詞。頂部及封面均提供後台 Demo 連結。
